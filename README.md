# Three Stones v2.3 Ranking and Stats

This version adds Phase 3 features:

- Local player statistics
- Ranking points
- Rank titles
- Match history
- Win rate
- Best time
- Fewest moves
- Reset stats button
- Stats panel on home screen
- Match result saving for PC and online games

Stats are saved in browser `localStorage` first. This keeps the game simple and avoids requiring a database. A future phase can move stats to MongoDB, SQLite, Firebase, or Supabase.

## Run

```bash
npm install
npm start
```

Open:

```text
http://localhost:3000
```
